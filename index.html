Projeto principal

Acompanha Aí

Plataforma web para acompanhar candidaturas e processos seletivos, com contas de usuários, filtros, paginação e histórico de etapas. API em camadas com controllers, services, repositories, DTOs e entidades, e interface em Angular.

  • Autenticação por sessão com Spring Security, proteção CSRF e isolamento de dados por usuário.
  • PostgreSQL, Spring Data JPA, Hibernate e Flyway para modelar relacionamentos e versionar o banco.
  • Transações, deduplicação de vagas e controle de versão que rejeita atualizações desatualizadas (HTTP 409).
  • Testes com JUnit, Mockito e MockMvc, pipeline CI/CD, Docker, API documentada com OpenAPI e cenários prontos no Postman.
